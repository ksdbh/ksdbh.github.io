# Sean Hayes engineering portfolio

An evidence-first portfolio for Sean Hayes, a Full Stack Engineer positioned toward
backend, platform, and cloud engineering opportunities.

## Current phase

Phase 1 establishes the application foundation before final page design:

- Next.js App Router with static export.
- Strict TypeScript and evidence-first content schemas.
- Route boundaries for Home, Work, About, Lab, and flagship case studies.
- Design tokens and accessible layout primitives.
- ESLint, Prettier, Vitest, and CI quality gates.
- Preserved legacy site under `legacy/index.html`.

Final project prose, animation integration, and page polish are intentionally deferred
until content and confidentiality review are complete.

## Commands

```bash
npm install
npm run dev
npm run check
npm run build
```

The static production site is written to `out/`.

## Content standards

- `docs/editorial-style-guide.md` is authoritative for portfolio writing.
- `docs/content-inventory.md` records currently defensible evidence.
- `docs/content-gaps.md` records unresolved factual questions.
- `docs/visual-storytelling.md` governs meaningful motion and diagrams.
